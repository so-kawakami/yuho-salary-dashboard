# 有報年収ダッシュボード コンサルティングレポート

作成日: 2026-05-02

## 現状の評価

### 良い点

- SEO基本設定（sitemap.xml, robots.txt, OG/Twitter Card, Google Search Console連携）済み
- 企業個別ページで `generateMetadata` による動的meta生成 → SEO的に有効
- 3,000社以上の企業個別ページを静的生成 → Google インデックスのボリュームが大きい
- AdSense導入済み
- `force-static` でパフォーマンス良好

---

## 閲覧数を増やすための改善提案

### 1. コンテンツSEO強化（最優先）

| 課題 | 対策 |
|------|------|
| ランキングが100社しかない | `getRanking(100)` → **全社表示**（ページネーション付き）にすれば、ロングテール検索で大量流入が見込める |
| 企業ページにテキストコンテンツが少ない | 「○○の年収は△△万円で、業界平均□□万円と比較して…」のような**自動生成テキスト**を追加 → Google が評価しやすくなる |
| h1タグが明示的でない | 各ページに適切な`<h1>`を配置（現在はh2がメイン） |
| 業界別ページにURLが1つしかない | `/industries/IT` `/industries/金融` など**業界別個別ページ**を作ればインデックス数が大幅増加 |

### 2. 検索流入を狙うページ追加

よく検索されるキーワードに対応するページを増やす：

- **「○○ 年収」ページ**（企業名 × 年収）→ 既にある
- **「○○業界 年収ランキング」ページ** → `/industries/[slug]` を新設
- **「年収○○万円の企業一覧」ページ** → `/salary-range/800` のような新ページ
- **「都道府県別 年収ランキング」** → データに所在地があれば非常に強い
- **「年収が上がった企業ランキング」** → 前年比データがあれば差別化になる
- **ブログ/コラムセクション** → 「2026年版 年収が高い業界TOP10」のような記事ページ

### 3. テクニカルSEO

| 項目 | 現状 | 改善案 |
|------|------|--------|
| 構造化データ（JSON-LD） | なし | Organization, BreadcrumbList, FAQ schema を追加 |
| パンくずリスト | 企業ページのみ | 全ページに統一的に追加 |
| 内部リンク | 弱い | フッター・サイドバーで関連ページへ相互リンク |
| canonical URL | 未設定 | `metadataBase`で対応済みだが明示的に追加推奨 |
| OG画像 | なし | 動的OG画像生成（`opengraph-image.tsx`）で SNS シェア率UP |

### 4. ユーザー体験改善（直帰率を下げる）

- **企業ページ → 同業他社リンク** → peers は取得済みだが、もっと目立たせる
- **「この企業を見た人はこちらも」** セクション追加
- **年収比較ツール**：2社を選んで比較できる機能 → 滞在時間UP & バイラル性
- **SNSシェアボタン** → 「自分の年収偏差値をシェア」は拡散力が高い

## 収益化の改善提案

### 1. AdSense最適化

- 現在はスクリプトを入れただけ → **広告ユニットを明示的に配置**する必要あり
- 推奨配置場所:
  - ランキングテーブルの途中（5社ごとに1つ）
  - 企業詳細ページの中間
  - 検索結果の上部
- レスポンシブ広告ユニットを使う

### 2. アフィリエイト連携

- 転職サイト（doda, リクナビNEXT, ビズリーチ等）のアフィリエイトリンク
  - 例：「この企業に転職するなら → [ビズリーチで求人を見る]」
  - **年収データサイトとの親和性が非常に高い**
- 年収が高い企業ページに「この企業の求人を探す」CTA

### 3. 追加収益源

- **API提供**（有料）：年収データをAPI経由で提供
- **プレミアム機能**：詳細な年収推移グラフ、企業比較ツールの無制限利用

## 優先度の高い施策 TOP5

1. **業界別個別ページ** (`/industries/[slug]`) の新設 → インデックス数 × SEO
2. **構造化データ（JSON-LD）** 追加 → Google検索でリッチリザルト表示
3. **動的OG画像生成** → SNSシェア時の見栄え向上
4. **AdSense広告ユニット配置** → スクリプトだけで広告が表示されていない可能性あり
5. **転職アフィリエイトリンク** → 収益の柱になりうる
