## 1. 現在地とゴールのギャップ

### 現状（過去28日・検索経由）

| 指標 | 値 |
|---|---|
| 検索クリック | 81回/月 |
| 表示回数 | 4,549回/月 |
| CTR / 平均順位 | 1.8% / 16.9位（2ページ目） |
| 表示があったページ | 655 / 総4,743ページ（**14%しか戦えていない**） |

### ゴールの分解（PVの方程式）

```
月間PV = 検索クリック × 回遊率（PV/セッション） + 直接・SNS流入

10,000 PV ≒ 4,000クリック × 2.2 PV/セッション + α（SNS・リピート ~1,000PV）
```

つまり **検索クリックを月4,000回（現状の約50倍）** に伸ばすのが本線。
内訳目標:

| 流入源 | 現状 | 目標 | 根拠 |
|---|---|---|---|
| 役員報酬テーマ | 39 | 500 | pos14.8→3位以内でクリック5〜10倍＋派生ページ |
| 企業詳細（会社名 年収/給与） | 7 | 2,500 | 4,069ページ×ロングテール。pos20-45→1ページ目 |
| 比較・年収帯・業界・チェッカー | 20 | 700 | 受け皿は構築済み。インデックス浸透待ち |
| トップ・その他 | 15 | 300 | ブランド検索の成長 |

### 3つの構造的ボトルネック（= 攻めどころ）

1. **インデックス不足**: 4,743ページ中、表示があるのは655ページ。まず「戦場に立つ」こと
2. **順位が2ページ目**: 表示はされるがpos16-45でクリックされない。コンテンツの質と内部リンクで押し上げる
3. **データが1年古い** ⚠️: サイトは2025年3月期のまま。**2026年3月期の有報は6月末に提出済みで未反映**。
   「役員報酬ランキング 2026」等の年付きクエリで戦うのに、中身が2025年データでは信頼と順位を失う
